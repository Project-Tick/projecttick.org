## Advanced Windows Install Options

### Chocolatey Package

MeshMC is available on Chocolatey. You can install it using the following command:

```cmd
choco install meshmc
```

### Scoop Package

MeshMC is available on Scoop. You can install it using the following command:

```cmd
scoop bucket add games
scoop install meshmc
```
